# DISC CHAOS

A cozy, chaotic first-person co-op cleanup game for Android (Godot 4.7, GDScript only).
Huge game collections have been wrecked: thousands of discs on the floor, in the wrong cases,
hidden under beanbags. Match every disc to its case **and edition**, close it, and shelve it in
the right platform section, A–Z. 1–4 players over LAN or a phone hotspot.

Everything is original and generated by code: 480 fictional games on 8 fictional platforms,
procedural cover art, procedural rooms and props, bean characters, synthesized audio.

---

## Download

Every milestone is published as a GitHub Release with a signed APK attached
(`DiscChaos-vX.Y.apk`). On your phone: open the Releases page, download the APK, allow
"install unknown apps" for your browser, install. Target device: Samsung Galaxy S25 Ultra
(any arm64 Android 7.0+ phone with Vulkan works).

## How to play

1. **Find a disc** and grab it. Face-down discs only show their rainbow underside: flip them
   (Interact) or inspect them to read the label.
2. **Find its case.** The disc label uses the same art, colors and logo as its box. Editions
   matter: a *Golden Greats* reprint disc only fits the Golden Greats case, a steelbook disc its
   steelbook.
3. **Slot it in.** Hold an open case and grab the disc to scoop it in, or hold the disc and
   grab an open case. Wrong disc inside? Hold the case open and Interact to take it out.
4. **Close the case** (Interact) and carry it to the shelf of its platform. Shelves have
   platform banners and A–Z dividers; a glowing ghost shows where it will snap.
5. **Shelve it.** A case counts as solved when it is closed, holds exactly its own disc(s) and
   sits in the right section. Progress bars per section and for the whole level are top-left.

Extra tricks: carry stacks of up to 6 closed cases, throw things to friends (hold to charge),
lay items out on the sorting table, search beanbags/drawers/boxes for hidden items, use the
**Sort Scanner** (highlights where the held item belongs; recharges, or always on in Casual mode).
Sprinting across disc piles is a bad idea. Results give 1–3 stars and unlock bonus cosmetics.

## Controls

**Touch (default):** left side floating joystick, drag anywhere on the right to look.
Buttons: Grab (contextual: Grab / Insert / Scoop / Stack / Shelve / Place / Drop), Interact
(Open / Close / Take out / Flip / Search), Throw (hold to charge), Inspect, Jump, Crouch,
Sprint (toggle), Scanner, Emotes, Quick chat, Pause. Settings → Controls lets you change button
size, opacity, look sensitivity, invert Y, FOV, haptics and **drag buttons to a custom layout**.

**Keyboard & mouse:** WASD move · mouse look (click to capture) · Shift sprint · Ctrl/C crouch ·
Space jump · E or left click grab · F interact · Q or right click throw · R or middle click
inspect · G drop · Tab scanner · T emotes · Y quick chat · L flashlight · Esc pause · F3 FPS.

**Gamepad (Bluetooth):** left stick move · right stick look · A jump · X / RT grab · Y interact ·
RB throw · LT / R3 inspect · B crouch · L3 sprint · LB scanner · D-pad up emotes / down chat /
left flashlight / right drop · Start pause.

## Co-op: hosting and joining

* **Host:** Main menu → Host. You get a lobby with a **room code** (and your IP). Pick the level,
  wait until everyone is ready, Start. The host is authoritative for every item.
* **Join:** Main menu → Join. Games on the same Wi-Fi (or on the hotspot you're connected to)
  appear automatically (UDP broadcast on port 47011). Or type the **room code** (it encodes the
  host's IP + port), or the **IP** manually.
* **Phone hotspot:** the phone sharing the hotspot should Host; the others connect to its
  hotspot and Join. Discovery broadcasts on both the global and the subnet broadcast address.
* Ports: game UDP 47010 (ENet), discovery UDP 47011.
* Late joiners get a full state sync. If the host leaves, everyone returns to the menu with a
  message. Players dropping mid-level drop whatever they were holding.
* The host can save mid-level (Pause → Save game, also automatic when leaving) and resume later
  from the level select (**Continue**).

### Adding an internet relay later

All networking goes through `scripts/net/net.gd`. Only `_make_server_peer()` and
`_make_client_peer()` create the transport (`ENetMultiplayerPeer` today). Gameplay uses Godot
high-level RPCs on the `Game` autoload, which work with any `MultiplayerPeer`. To play over the
internet, add a relay transport there, e.g. a `WebSocketMultiplayerPeer` connected to a tiny relay
server that forwards packets between room members, or `WebRTCMultiplayerPeer` with a signalling
server; extend room codes to carry a relay room id instead of an IP. No gameplay code changes.

## Replacing cover art with your own images

Put PNGs in `res://covers_override/` (in the project) or `user://covers_override/` (on device:
`/sdcard/Android/data/com.discchaos.game/files/covers_override/`):

| file | used for |
|---|---|
| `<game_id>_front.png` | front cover (all editions) |
| `<game_id>_back.png` | back cover |
| `<game_id>_spine.png` | spine (horizontal or vertical, it is rotated automatically) |
| `<game_id>_disc.png` | disc label (square) |
| `<game_id>_steelbook.png` | steelbook front |
| `<game_id>_<edition>_<part>.png` | edition-specific (`std`, `steel`, `ce`, `gold`) |

`game_id` is the catalog id shown in each back cover barcode, e.g. `ox5_012`, `pip_003`
(platform code + index). Recommended sizes: front/back 410×528, spine 528×64, disc 512×512.
Delete the cover cache in Settings → Gameplay after changing files on a phone.

## Building the APK

One command reproduces the whole export (downloads everything it needs):

```bash
./build.sh            # -> build/DiscChaos-v<VERSION>.apk  (tests run first)
SKIP_TESTS=1 ./build.sh
```

`tools/setup_toolchain.sh` installs Godot 4.7.2 + export templates (from the official
godotengine.org mirror, GitHub releases as fallback), OpenJDK 17, Android SDK command-line tools,
platform-tools, build-tools 35.0.1, platform android-35, generates a debug keystore and writes
Godot's editor settings by script. The export preset is arm64-v8a only, landscape,
`com.discchaos.game`, min SDK 24, permissions INTERNET, ACCESS_NETWORK_STATE, ACCESS_WIFI_STATE,
CHANGE_WIFI_MULTICAST_STATE, signed with the debug key.

**CI backup route:** `.github/workflows/android.yml` runs the same `build.sh` on GitHub Actions
and attaches the APK to a Release when you push a tag `vX.Y`, run it manually, or push a commit
that changes `VERSION` with `[release]` in its message.

## Tests

```bash
tools/run_tests.sh            # all suites
tools/run_tests.sh levels     # generator validation + bot solver + playtime estimate
tools/net_test.sh             # headless host + 2 clients on localhost
```

* **scripts** – every script parses, every scene loads.
* **levels** – for every level and two seeds: every disc has exactly one correct case, every
  product exactly one shelf slot with room, A–Z ranges, nothing inside walls/outside the map,
  save/sync round trip, and a bot that solves the level 100% using only gameplay rules while
  estimating solo / 4-player time (report in `tests/out/level_report.txt`).
* **gameplay** – the real scene: solving through requests, throwing, stack carry, grab ownership,
  stashes, save/resume.
