# Tests

Run everything headless: `tools/run_tests.sh` (or one suite: `tools/run_tests.sh reg_cart`).
Multi-process co-op test: `tools/net_test.sh`.

| Suite | Covers |
|---|---|
| `scripts` | every script parses, every scene loads |
| `levels` | generator invariants + bot solve for 2 seeds per level |
| `gameplay` | real-scene gameplay (requests, throw, stack, stash, save/resume, cart, completion) |
| `sweep` | the level validator + bot over 188 generated levels, ~20 s (`-- --seeds=quick` = 38 levels) |
| `reg_targeting` | M1/A1 aiming priority for items inside containers and carts |
| `reg_world` | M1/A2 window colliders and out-of-bounds recovery |
| `reg_cart` | M1/A5 cart collision, sliding, slip and release |
| `reg_saves` | M1/A3, A4, C1 save format, migration, resume failure handling, held items |
| `reg_misc` | M1/B13 client clock, B15 autosave, C7 layout, C9 validator |

`tests/fixtures/saves/` holds **real legacy (v1.0-format) saves** generated by the v1.0 code, used to prove migration.
